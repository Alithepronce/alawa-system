# إصدار تراخيص العلوة دون اتصال

هذه أداة محلية لإصدار ملفات تراخيص مرتبطة ببصمة جهاز عميل. لا تتصل بالإنترنت ولا تُضمّن المفتاح الخاص في برنامج العميل.

## إعداد المفتاح مرة واحدة

احتفظ بملف `license-server/license-private.pem` الموجود عندك في مكان آمن ومشفّر. لا ترفع هذا الملف إلى GitHub ولا ترسله للعميل. المفتاح العام `server/license-public-key.pem` آمن للتوزيع ومضمّن في التطبيق.

إذا لم يكن ملف المفتاح الخاص موجوداً، أنشئ زوج مفاتيح باستخدام `npm run create-key` داخل `license-server`، ثم استبدل المفتاح العام في `server/license-public-key.pem` بالمفتاح العام الجديد وأعد بناء البرنامج. لا تنفذ الأمر إذا كان لديك المفتاح الخاص الحالي؛ إنشاء زوج جديد يجعل الملفات القديمة غير قابلة للتحقق.

## إصدار ترخيص

1. العميل يختار «حفظ طلب التفعيل لهذا الجهاز» داخل التطبيق ويرسل لك ملف `alawa-activation-*.json`.
2. على جهازك، افتح `index.html` في إصدار حديث من Microsoft Edge أو Google Chrome.
3. اختر ملف الطلب، وملف المفتاح الخاص عندك، و`server/license-public-key.pem` من نسخة المصدر المطابقة للإصدار الذي يستخدمه العميل.
4. اترك تاريخ الانتهاء فارغاً لترخيص دائم، أو اختر تاريخاً. الأداة تتحقق محلياً من تطابق زوج المفاتيح قبل التوقيع.
5. أرسل ملف `ALAWA-....alawa-license.json` الناتج للعميل؛ يختاره في شاشة التفعيل.

لا يُحفظ المفتاح الخاص في الأداة ولا يُرسل إلى أي خدمة. لتغيير الجهاز، أصدر ملف ترخيص جديد بطلب تفعيل الجهاز الجديد. الترخيص الدائم لا يمكن إيقافه عن بُعد، وقد يقبل العميل تعديل البرنامج لكسر الحماية؛ ربط الجهاز يردع النسخ العادي فقط ولا يوفر حماية مطلقة.
